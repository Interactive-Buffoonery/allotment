# Allotment Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the approved 2026-08-24 rebrand spec §2–§8: new theme (mauve, deep green, purple bars), dark mode v2, Fraunces wordmark, seedling icon + launch screen, two-step provider setup flow, reworked Settings, bars-only Current tab.

**Architecture:** All changes live in the existing SwiftUI app (`Allotment/`). A new `Provider` enum in Models is the only new type; views get a reusable `ProviderPickerView`/`ProviderKeyView` pair used by both first-run setup and Settings. Brand assets (icon, launch lockup) are generated by a one-off Swift/CoreGraphics script committed under `scripts/`.

**Tech Stack:** SwiftUI, XCTest (XCTestCase), XcodeGen (project.yml), CoreGraphics/CoreText for asset generation, fontTools for pinning the Fraunces variable font.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-24-allotment-rebrand-design.md` — sections 2–8 are in scope; §1 (rename) is already shipped.
- Copy rules (spec §9): never use the words plot, bed, shed, till, sow, grow, harvest, water; garden identity is visual only. Labels stay functional.
- Colors: mauve `#c6A0F6` = `rgb(0.776, 0.627, 0.965)`; deep green accent = `rgb(0.14, 0.51, 0.37)`; dark paper = `rgb(0.15, 0.13, 0.20)`; dark sticker shadow glow = `rgba(0.67, 0.59, 0.94, 0.35)`.
- Only the wordmark uses Fraunces. Data/labels/numbers stay SF.
- Fraunces is OFL — embedding allowed, no attribution required.
- Out of scope (spec §10): Codex implementation, iCloud sync implementation, history-chart redesign, iPad layout changes, haptics/animations.
- Test command (whole plan): `xcodegen generate` when project.yml changes, then `xcodebuild -scheme Allotment -destination 'platform=iOS Simulator,name=iPhone 17' test`. If no `iPhone 17` simulator exists, pick one from `xcrun simctl list devices available | grep iPhone` and use it for the rest of the plan.
- Build command: `xcodebuild -scheme Allotment -destination 'platform=iOS Simulator,name=iPhone 17' build`
- Commits: conventional format, no period, imperative, no Claude credit, no emojis. Use `trash` (not `rm`) for file deletion, then `git add -A`.

- [ ] **Step 1: Write the generator script**

```swift
import CoreGraphics
import CoreText
import Foundation
import ImageIO

// Renders the Allotment brand assets: AppIcon.png (1024px) and the
// LaunchLockup imageset PNGs (Task 9). Run: swift scripts/render-brand-assets.swift

let ink = CGColor(red: 0.18, green: 0.16, blue: 0.29, alpha: 1)
let paper = CGColor(red: 1.0, green: 0.99, blue: 0.97, alpha: 1)
let leafGreen = CGColor(red: 0.38, green: 0.76, blue: 0.62, alpha: 1)
let mauve = CGColor(red: 0.776, green: 0.627, blue: 0.965, alpha: 1)

// Design space is 330x107 points; scale maps it to the target pixel size.
func drawSprout(_ ctx: CGContext, silhouette: Bool, scale: CGFloat) {
    // Soil band: rounded mauve bar with ink outline.
    let soil = CGRect(x: 112 * scale, y: 600 * scale, width: 776 * scale, height: 96 * scale)
    let soilPath = CGPath(roundedRect: soil, cornerWidth: 48 * scale, cornerHeight: 48 * scale, transform: nil)

    // Stem.
    var stem = CGMutablePath()
    stem.move(to: CGPoint(x: 500 * scale, y: 636 * scale))
    stem.addQuadCurve(to: CGPoint(x: 500 * scale, y: 360 * scale), control: CGPoint(x: 512 * scale, y: 500 * scale))

    // Two leaves, mirrored quad-curve teardrops.
    func leaf(tipX: CGFloat, tipY: CGFloat, control1: CGPoint, control2: CGPoint) -> CGMutablePath {
        let p = CGMutablePath()
        p.move(to: CGPoint(x: 500 * scale, y: 420 * scale))
        p.addQuadCurve(to: CGPoint(x: tipX * scale, y: tipY * scale), control: control1)
        p.addQuadCurve(to: CGPoint(x: 500 * scale, y: 420 * scale), control: control2)
        p.closeSubpath()
        return p
    }
    let leftLeaf = leaf(tipX: 300, tipY: 250,
                        control1: CGPoint(x: 340 * scale, y: 350 * scale),
                        control2: CGPoint(x: 380 * scale, y: 200 * scale))
    let rightLeaf = leaf(tipX: 700, tipY: 250,
                         control1: CGPoint(x: 660 * scale, y: 350 * scale),
                         control2: CGPoint(x: 620 * scale, y: 200 * scale))

    if silhouette {
        ctx.setFillColor(ink)
        ctx.setStrokeColor(ink)
    } else {
        ctx.setFillColor(mauve)
        ctx.setStrokeColor(ink)
    }
    ctx.setLineWidth(22 * scale)
    ctx.setLineCap(.round)

    ctx.addPath(soilPath)
    ctx.fillPath()
    ctx.addPath(soilPath)
    ctx.strokePath()

    ctx.setFillColor(silhouette ? ink : leafGreen)
    ctx.addPath(leftLeaf)
    ctx.fillPath()
    ctx.addPath(leftLeaf)
    ctx.strokePath()
    ctx.addPath(rightLeaf)
    ctx.fillPath()
    ctx.addPath(rightLeaf)
    ctx.strokePath()

    ctx.addPath(stem)
    ctx.strokePath()
}

func makeContext(pixels: Int) -> CGContext {
    let space = CGColorSpaceCreateDeviceRGB()
    return CGContext(data: nil, width: pixels, height: pixels,
                     bitsPerComponent: 8, bytesPerRow: 0, space: space,
                     bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
}

func savePNG(_ image: CGImage, to path: String) {
    let url = URL(fileURLWithPath: path) as CFURL
    let dest = CGImageDestinationCreateWithURL(url, "public.png" as CFString, 1, nil)!
    CGImageDestinationAddImage(dest, image, nil)
    precondition(CGImageDestinationFinalize(dest), "failed to write \(path)")
}

// App icon: 1024x1024, paper background, offset ink shadow behind the sprout.
let iconSize = 1024
let ctx = makeContext(pixels: iconSize)
ctx.setFillColor(paper)
ctx.fill(CGRect(x: 0, y: 0, width: iconSize, height: iconSize))
let iconScale = CGFloat(iconSize) / 1000.0
ctx.saveGState()
ctx.translateBy(x: 16, y: -18)
drawSprout(ctx, silhouette: true, scale: iconScale)
ctx.restoreGState()
drawSprout(ctx, silhouette: false, scale: iconScale)
savePNG(ctx.makeImage()!, to: "Allotment/Assets.xcassets/AppIcon.appiconset/AppIcon.png")
print("wrote AppIcon.png")
```

Note: CGContext y-axis runs bottom-up in this raw bitmap context, so the soil band at y=600 renders *below* center — verify visually in Step 3 and, if the composition is upside-down or cramped, flip with `ctx.translateBy(x: 0, y: CGFloat(iconSize)); ctx.scaleBy(x: 1, y: -1)` right after `makeContext` or adjust the constants. The exact composition may take one tweak round; that's expected and fine.

var error: Unmanaged<CFError>?
precondition(CTFontManagerRegisterFontsForURL(fontURL, .process, &error), "register Fraunces")

func renderLockup(scale: CGFloat) -> CGImage {
    let width = Int(330 * scale)
    let height = Int(107 * scale)
    let space = CGColorSpaceCreateDeviceRGB()
    let ctx = CGContext(data: nil, width: width, height: height,
                        bitsPerComponent: 8, bytesPerRow: 0, space: space,
                        bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)!
    // Mini sprout on the left: scaled-down version of the icon composition (no shadow).
    ctx.saveGState()
    ctx.translateBy(x: 4 * scale, y: -20 * scale)
    drawSprout(ctx, silhouette: false, scale: 0.13 * scale)
    ctx.restoreGState()

    let font = CTFontCreateWithName("Fraunces-SemiBold" as CFString, 52 * scale, nil)
    let attrs: [NSAttributedString.Key: Any] = [
        NSAttributedString.Key(kCTFontAttributeName as String): font,
        NSAttributedString.Key(kCTForegroundColorAttributeName as String): ink,
    ]
    let line = CTLineCreateWithAttributedString(NSAttributedString(string: "Allotment", attributes: attrs))
    ctx.textPosition = CGPoint(x: 116 * scale, y: 28 * scale)
    CTLineDraw(line, ctx)
    return ctx.makeImage()!
}
